How this set was built, and what is missing

This is 83 customers, not the 100 asked for. The limit is the data, not the filter: height is volunteered far less often than bra size or weight, and the rule was to include a customer only where both height and a size are stated outright. Roughly half the customers who gave a height never named a size (“I went by the size chart and bought what was recommended”), and those were dropped rather than guessed at. CommSlayer’s content search also caps at 25 results per query and cannot paginate, so this is everything ~22 height-phrase searches surfaced.

Where a customer gave a bra size but never a tank size, the bra size is recorded and tagged Bra size worn; a tank size is tagged Tank size ordered. Order numbers appear only where the customer quoted one.
